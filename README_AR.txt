MY FOOTBALL PRO - ملفات المشروع الأولية

مهم:
- هذا مشروع Android قابل للبناء، وليس APK جاهزاً.
- التحليل الحالي نسخة أولية تستخدم TheSportsDB (المفتاح العام التجريبي 3).
- تغطية الفرق والنتائج ليست شاملة، وقد لا يعمل البحث مع كل الأسماء.
- النسب تقريبية وتجريبية وليست دقة مضمونة أو توصية للمراهنة.

طريقة استخراج APK من الهاتف عبر GitHub:
1) افتح https://github.com من Chrome وأنشئ حساباً أو سجّل الدخول.
2) اضغط + ثم New repository. سمّه MY-FOOTBALL-PRO واجعله Public أو Private.
3) ارفع محتويات هذا المجلد كاملة إلى المستودع مع الحفاظ على أسماء المجلدات.
   الأسهل: فك ضغط ZIP أولاً، ثم من صفحة المستودع Add file > Upload files وارفع الملفات والمجلدات.
4) افتح تبويب Actions داخل المستودع. إذا طلب GitHub تفعيل Actions فوافق.
5) اختر workflow باسم Build Android APK ثم Run workflow.
6) انتظر حتى ينتهي البناء بنجاح (علامة خضراء).
7) افتح صفحة التشغيل الناجح، وانزل إلى Artifacts، وحمّل MY-FOOTBALL-PRO-APK.zip.
8) فك ضغطه في الهاتف، ثم افتح app-debug.apk وثبّته. قد يطلب Android السماح بالتثبيت من Chrome أو Files؛ اسمح لهذا المصدر فقط عند الحاجة.

إذا فشل البناء:
- تأكد أنك رفعت الملفات من داخل المجلد، وليس مجلد ZIP فقط.
- يجب أن يظهر settings.gradle و build.gradle في جذر المستودع.
- افتح Actions واقرأ أول خطأ أحمر وأرسله لي.

الملف الناتج Debug APK للتجربة الشخصية. للنشر العام يلزم إعداد توقيع إصدار Release ومراجعة الخصوصية ومصدر البيانات.
